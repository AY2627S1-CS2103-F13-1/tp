Use these commands in the input above.

CONTACTS

    add n/NAME p/PHONE e/EMAIL a/ADDRESS [t/TAG]...
    Required: name, phone, email, address.
    Example: add n/John Doe p/98765432 e/john@example.com a/Clementi

    edit ID [n/NAME] [p/PHONE] [e/EMAIL] [a/ADDRESS] [t/TAG]...
    Required: contact ID and at least one change.
    Example: edit 3 p/91234567

    delete ID
    Example: delete 3

    clear
    Removes all contacts.

DISCOVER

    list [archive | all]
    Shows active contacts by default, archived contacts with "archive", and both active and archived contacts with "all".
    Examples: list; list archive; list all

    find [GENERAL_SUBSTRING] [n/NAME] [p/PHONE] [e/EMAIL] [a/ADDRESS] [t/TAG]...
    Searches all fields with a general substring and specific fields with some prefixed substrings.
    All conditions must match.
    If the general substring is used with prefixed substrings, the general substring must be placed first.
    Examples: find oak; find n/Al e/example.com; find example n/Al t/fri

    sort FIELD [ORDER]
    Sorts contacts by field. ORDER: asc or desc (default: asc).
    Examples: sort name asc; sort tag desc

    filter t/TAG [t/TAG]...
    Shows contacts matching all specified exact tags.
    Example: filter t/tech t/finance

ORGANISE

    tag ID t/TAG [t/TAG]...
    Adds tags without removing existing tags.
    Example: tag 3 t/housing policy t/expert

    untag ID t/TAG [t/TAG]...
    Removes specified tags.
    Example: untag 3 t/expert

    archive ID
    Archives a contact.
    Example: archive 3

    restore ID
    Restores an archived contact to the active contacts.
    Example: restore 3

APPLICATION

    undo
    Reverses the most recent change to contacts. Takes no parameters. Undo up to 20 changes.
    Example: delete 3, then undo to bring the contact back.

    redo
    Reapplies the last change you undid. Takes no parameters.
    Example: delete 3, then undo, then redo to delete the contact again.

    export PATH
    Exports all contacts to a JSON backup.
    Example: export backup

    load PATH
    Replaces current contacts with data from a JSON backup.
    Example: load backup.json

    help
    Displays this command guide.

    exit
    Closes ByLine.
